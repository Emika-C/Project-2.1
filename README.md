# Project-2.1

Interactive browser platformer game with checkpoints.

## Play

1. Open [index.html](index.html) in a browser.
2. Or run a quick local server from this folder:
	- `python3 -m http.server 8000`
	- then open `http://localhost:8000`

## Controls

- Jump: Up Arrow, W, Space
- Move Left: Left Arrow, A
- Move Right: Right Arrow, D

## Game Goal

Start on a grassy dirt ground with flowers, then climb higher and higher on platforms toward space.
Touch checkpoint flags to set respawn points when you fall.
